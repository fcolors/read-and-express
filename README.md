# Read and Express（读懂，再表达）

一个轻量的科研阅读与英语表达练习 skill，使用 MIT 许可证。围绕你正在阅读的论文练习：尽量用英语表达，卡住时可以用中文，也可以中英混写。

每轮回复固定包含两部分：

1. **英文回应**：用简短、易懂的英语回答实际问题，最后提出一个适合用 1–3 句英语回答的小问题。
2. **中文纠正**：提供保留原意的自然英文表达，每轮最多解释三个重点。已经正确的英语不会被强行修改；中文输入会得到英文表达示范。

## 开始使用

将本仓库的 [`skills/read-and-express/`](skills/read-and-express/) 安装到当前工具支持的技能目录，或使用 [Research Agent Template（RAT）](https://github.com/fcolors/research-agent-template) 中同步的 `.agents/skills/read-and-express/`。

在自己的私有调研项目中调用：

```text
$read-and-express
请开始阅读与英语表达练习。我会尽量用英语，不会表达时用中文。
下面是我正在读的段落：……
```

技能能否自动被发现取决于使用的工具。如果没有显示在技能列表中，可以让模型直接读取其 `SKILL.md`。本技能不需要额外的运行时依赖。

## 自动笔记与跨对话恢复

每个完成的练习轮次都会在回复前保存到当前私有项目，默认结构为：

```text
笔记/
└── 英语练习/
    ├── index.md          # 学习偏好、当前进度、待回答问题、日期索引
    └── YYYY-MM-DD.md     # 当天各轮的原表达、修改版、学习要点与下一步
```

同一天的记录追加到同一文件，默认使用UTC+8。涉及文献时记录已知的 DOI 和页码或图号；缺少信息时明确标记，不编造来源。

更换模型或开启新对话后，可以这样恢复：

```text
请使用 read-and-express，先读取本项目的
笔记/英语练习/index.md 和最近的日志，从上次的问题继续。
```

保存和恢复需要模型能够访问项目文件。日志保留学习进度和关键表达，不是完整聊天备份；技能不会在对话结束后后台运行。如果保存失败，会明确告知。

## 与 RAT 的联动

RAE 是技能源码仓库；RAT 按其现有 Zotero 技能的方式，通过 GitHub Actions 每六小时或手动同步一份技能副本：

```text
RAE main：skills/read-and-express/
                  ↓ 单向同步
RAT main：.agents/skills/read-and-express/
```

维护时先修改并发布 RAE，再由 RAT 的 `sync-read-and-express.yml` 更新副本。首次接入应先发布 RAE 技能，再发布 RAT 的工作流，并手动运行一次验证。直接修改 RAT 的技能副本，会在后续同步时被覆盖。

只同步技能目录及其中的 MIT 许可证，不同步本仓库的 README、测试记录或个人学习日志。RAT 原有的根许可证保持不变。
